Fractal composition.

The primitives of software code are quite simple.

Let's take a pure function. It takes some input parameters and transforms them to a result. The transformation might be algorithmically complicated but reasoning about the function is rather simple. Everything we need to know for understanding the logic of the function is local to it.

Properly composing higher level components out of lower level ones 
Why is software then so complicated at larger scale? 

Of course, whole systems have to deal with intricacies much more complicated than a pure function.
